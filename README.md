# 3D Lab Viewer — Feedback & Issues

This is the public issue tracker for [3D Lab Viewer](https://viewer.3dlab.id).

## How to Report

- **Bug?** → [Report a bug](https://github.com/Goodsmileduck/viewer.3dlab.id/issues/new?template=bug_report.yml)
- **Feature idea?** → [Request a feature](https://github.com/Goodsmileduck/viewer.3dlab.id/issues/new?template=feature_request.yml)
- **General feedback?** → [Open a discussion](https://github.com/Goodsmileduck/viewer.3dlab.id/issues/new?template=feedback.yml)

## About

3D Lab Viewer is a desktop and web 3D model viewer supporting STL, OBJ, STEP, 3MF, and GLB formats.

- **Web:** [viewer.3dlab.id](https://viewer.3dlab.id)
- **Desktop:** [https://viewer.3dlab.id/download](https://viewer.3dlab.id/download) (Windows, not signed)
